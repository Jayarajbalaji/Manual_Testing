The administra on wants to iden fy the longest con nuous sequence of sessions in which no student ID is repeated. Develop a solu on that determines the maximum length of such a sequence. 

~~~ python

def longest_attendance(a):
    seen = set()
    left = 0
    maximum = 0

    for right in range(len(a)):

        while a[right] in seen:
            seen.remove(a[left])
            left += 1

        seen.add(a[right])

        maximum = max(maximum, right - left + 1)

    return maximum


attendance = [101, 102, 103, 101, 104, 105]

print("Maximum length:", longest_attendance(attendance))

## 3. Rainwater Collec on System 
### A city installs buildings of different heights along a straight road. During rainfall, water gets collected between taller buildings. The engineering team needs to calculate the total amount of water that can remain trapped a er heavy rainfall based on the heights of the buildings. 

```python
def rainwater(a):
    left = 0
    right = len(a) - 1
    left_max = 0
    right_max = 0
    water = 0

    while left < right:
        if a[left] < a[right]:
            if a[left] >= left_max:
                left_max = a[left]
            else:
                water += left_max - a[left]
            left += 1
        else:
            if a[right] >= right_max:
                right_max = a[right]
            else:
                water += right_max - a[right]
            right -= 1

    return water

print(rainwater([0,1,0,2,1,0,1,3,2,1,2,1]))
```
## output:
```
6
```

## 7. Bank Transaction Analysis 
### A bank stores transaction amounts for a customer's account. A continuous group of transactions may add up to a specific target amount. The auditing system needs to determine how many different continuous transaction groups produce exactly the specified amount.

```python
def count_groups(a, target):
    total = 0
    count = 0
    seen = {0: 1}

    for x in a:
        total += x

        if total - target in seen:
            count += seen[total - target]

        seen[total] = seen.get(total, 0) + 1

    return count

print(count_groups([1, 2, 3, -2, 2], 3))
```
## output:
```
3
```

## 8. Employee Skill Grouping 
### A company receives a list of employee skill codes represented as strings. Employees having the same set of characters in their skill codes belong to the same skill category, even if the characters appear in a different order. The HR system needs to organize employees into appropriate skill groups.

```python
def group_skills(words):
    groups = {}

    for word in words:
        key = ''.join(sorted(word))

        if key not in groups:
            groups[key] = []

        groups[key].append(word)

    return list(groups.values())

print(group_skills(["eat", "tea", "tan", "ate", "nat", "bat"]))
```
## output:
[['eat', 'tea', 'ate'], ['tan', 'nat'], ['bat']]

## 9. Network Packet Analysis 
### A network monitoring system receives packet identifiers in chronological order. The system must determine the longest sequence of consecutive packets whose identifiers form a continuous numerical sequence, regardless of their original order in the incoming data.

```python
def longest_consecutive(a):
    s = set(a)
    maximum = 0

    for x in s:
        if x - 1 not in s:
            count = 1

            while x + count in s:
                count += 1

            maximum = max(maximum, count)

    return maximum

print(longest_consecutive([100, 4, 200, 1, 3, 2]))
```
## output:
```
4
```

## 10. Hospital Appointment Scheduling
### A hospital receives appointment requests represented by starting and ending times. Some appointments overlap with each other. The scheduling system needs to combine overlapping appointment periods so that the final schedule contains only non-overlapping time ranges.

```python
def merge_appointments(a):
    a.sort()

    result = [a[0]]

    for start, end in a[1:]:
        if start <= result[-1][1]:
            result[-1][1] = max(result[-1][1], end)
        else:
            result.append([start, end])

    return result

print(merge_appointments([[1,3], [2,6], [8,10], [9,12]]))
```
## output:
```
[[1, 6], [8, 12]]
```
