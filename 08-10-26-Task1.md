## Selenium XPath – Real-Time Scenario

## Scenario

Imagine an **online student registration form**.

The automation must:

1. Open the registration page.
2. Enter student name.
3. Enter password.
4. Enter additional information.
5. Select a dropdown.
6. Select a checkbox.
7. Select a radio button.
8. Click Submit.
9. Verify successful submission.

## Test Cases

| TC | Real-Time Task | XPath Concept |
|---|---|---|
| TC01 | Open student registration page | `get()` |
| TC02 | Locate username | Attribute XPath |
| TC03 | Enter password | Attribute XPath |
| TC04 | Locate Submit | `text()` |
| TC05 | Locate textbox dynamically | `contains()` |
| TC06 | Locate element with prefix | `starts-with()` |
| TC07 | Find input using two attributes | `and` |
| TC08 | Find element using alternatives | `or` |
| TC09 | Find parent form | `parent` |
| TC10 | Find form from input | `ancestor` |
| TC11 | Find child inputs | `child` |
| TC12 | Find next element | `following` |
| TC13 | Find checkbox | Attribute + XPath |
| TC14 | Find radio button | Attribute + XPath |
| TC15 | Select dropdown | XPath + `Select` |
| TC16 | Find second textbox | XPath index |
| TC17 | Verify submitted message | `text()` |
| TC18 | Find all input fields | `find_elements()` |
| TC19 | Find dynamic element | `contains()` |
| TC20 | Complete registration automation | Multiple XPath concepts |
## PROGRAM:
```python

from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import Select
import time

driver = webdriver.Edge()
driver.get("https://www.selenium.dev/selenium/web/web-form.html")
time.sleep(1)

username = driver.find_element(By.XPATH, '//*[@id="my-text-id"]')
username.send_keys("JAYARAJ B")
time.sleep(1)

password = driver.find_element(By.XPATH, '//input[@type="password"]')
password.send_keys("JAI@123")
time.sleep(1)

submit_button = driver.find_element(By.XPATH, '//button[text()="Submit"]')
time.sleep(1)

text_box = driver.find_element(By.XPATH, '//input[contains(@id,"my-text")]')
time.sleep(1)

prefix_element = driver.find_element(By.XPATH, '//input[starts-with(@id,"my-")]')
time.sleep(1)

email_box = driver.find_element(By.XPATH, '//input[@type="text" and @name="my-text"]')
time.sleep(1)

element = driver.find_element(By.XPATH, '//input[@id="my-text-id" or @name="my-text"]')
time.sleep(1)

parent_form = driver.find_element(By.XPATH, '//*[@id="my-text-id"]/parent::label')
time.sleep(1)

form = driver.find_element(By.XPATH, '//*[@id="my-text-id"]/ancestor::form')
time.sleep(1)

child_input = driver.find_elements(By.XPATH, '//form/child::div//input')
print("Child input count:", len(child_input))
time.sleep(1)

following_element = driver.find_element(By.XPATH, '//*[@id="my-text-id"]/following::input[1]')
time.sleep(1)

checkbox = driver.find_element(By.XPATH, '//input[@type="checkbox"]')
if not checkbox.is_selected():
    checkbox.click()
time.sleep(1)

radio = driver.find_element(By.XPATH, '//input[@type="radio"]')
if not radio.is_selected():
    radio.click()
time.sleep(1)

dropdown = Select(
    driver.find_element(
        By.XPATH, '//select'
    )
)
dropdown.select_by_value("2")
time.sleep(1)

second_textbox = driver.find_element(
    By.XPATH, '(//input[@type="text"])[2]'
)
time.sleep(1)

all_inputs = driver.find_elements(By.XPATH, '//input')
print("TC18 - All Input Fields:", len(all_inputs) > 0)
print("Total Input Fields:", len(all_inputs))

dynamic_element = driver.find_element(
    By.XPATH, '//*[contains(@class,"form")]'
)
print("TC19 - Dynamic Element:", dynamic_element.is_displayed())

city = driver.find_element(
    By.XPATH,
    '/html/body/main/div/form/div/div[2]/label[2]/input'
)
city.send_keys("New York")

city_status = city.get_attribute("value") == "New York"
username_status = username.get_attribute("value") == "JAYARAJ B"
password_status = password.get_attribute("value") == "JAI@123"

dropdown_status = (
    dropdown.first_selected_option.get_attribute("value") == "2"
)

checkbox_status = checkbox.is_selected()
radio_status = radio.is_selected()

tc20_status = (
    username_status
    and password_status
    and city_status
    and dropdown_status
    and checkbox_status
    and radio_status
)

print("TC20 - Complete Registration:", tc20_status)

submit_button.click()
time.sleep(2)

message = driver.find_element(
    By.XPATH, '//*[contains(text(),"Received")]'
)

tc17_status = message.is_displayed()
print("TC17 - Submission Successful:", tc17_status)

time.sleep(10)
driver.quit()
```
